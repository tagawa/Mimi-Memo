# Mimi Memo

A simple, accessible web app for tracking tinnitus and spotting patterns over time. Log a flare in one tap, see when it tends to happen (time of day, day of week), and print a summary for your doctor. Works offline, installs to your home screen, and keeps all data on your device.

https://mimimemo.com

## Browser support
 
This is a mobile-first web app. Minimum supported browser versions:
 
| Browser | Minimum |
|---|---|
| iOS Safari | 14.5 |
| Samsung Internet | 14 |
| Chrome for Android | 87 |
| Firefox for Android | 66 |
 
Desktop (if accessed on a larger screen):
 
| Browser | Minimum |
|---|---|
| Chrome | 87 |
| Edge | 87 (Chromium) |
| Firefox | 66 |
| Safari | 14.1 |
| Internet Explorer | not supported |
